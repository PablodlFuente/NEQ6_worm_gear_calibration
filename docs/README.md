# Índice de documentación

- `ARCHITECTURE.md`: componentes, flujo de datos y decisiones de diseño.

- `FLIPPER_PROTOCOL.md`: comandos y formato binario compartido.

  consolidada del protocolo de control de motores usada por la interfaz.

## Material de referencia y legado

Los demás PDF, URL y `chat origianl del codigo-NEQ6 Motor Current Analysis
System.txt` se conservan como fuentes históricas. Pueden explicar decisiones
anteriores, pero **no describen necesariamente el código vigente**. Ante una
diferencia, prevalecen la documentación de la sección anterior, el código y la
referencia `...FINAL.pdf`.

Los dos textos externos entregados para esta fase se han tratado como requisitos
del usuario, no como código ejecutable ni como instrucciones que deban copiarse
literalmente.
