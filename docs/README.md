# Índice de documentación

## Documentación vigente

- `../wiki/Home.md`: manual detallado con capturas y navegación tipo Wiki.
- `FLIPPER_SETUP.md`: cableado, compilación, instalación, BLE y USB-COM.
- `FLIPPER_PROTOCOL.md`: comandos y formato binario compartido.
- `TEST_PROCEDURE.md`: preparación y ejecución segura de la calibración.
- `TROUBLESHOOTING.md`: diagnóstico por síntomas.
- `SkyWatcher_EQ6_Protocolo_Completo_Referenciado_FINAL.pdf`: referencia
  consolidada del protocolo de control de motores usada por la interfaz.

## Material interno

La arquitectura, conversaciones históricas y referencias redundantes se guardan
localmente en `docs/docs_dev/`. Esa carpeta está ignorada por Git porque no forma
parte de la documentación destinada al usuario final.
