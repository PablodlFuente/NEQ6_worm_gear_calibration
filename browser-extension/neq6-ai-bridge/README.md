# NEQ6 AI Browser Bridge

Extensión local opcional para ejecutar el análisis en ChatGPT, Qwen o Gemini y devolver la respuesta a la aplicación, sin usar sus API.

1. Descomprime `neq6-ai-browser-bridge.zip`.
2. Abre la página de extensiones del navegador y activa el modo desarrollador.
3. Elige «Cargar descomprimida» y selecciona esta carpeta.
4. Recarga `http://127.0.0.1:3000/`.

La extensión sólo tiene acceso al servidor local y a los tres chats declarados en `manifest.json`. No resuelve verificaciones ni inicia sesión.
